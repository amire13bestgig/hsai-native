# حق‌سنج — سورس نهایی Android بومی

این بسته شامل پروژه Kotlin / Jetpack Compose و اصلاح پوشش **۱۴ محاسبه‌گر** است؛ WebView نیست. تحویل فقط سورس است؛ APK، کلید امضا، اعتبارنامه حساب، توکن نشست، cache و build در آرشیو نیستند.

- [گزارش کامل تفکیک اپ و سرویس، شواهد و معیار پذیرش اصلاحات](docs/SERVER-API-FINDINGS.fa.md)
- [نتیجه کامپایل، آزمون و Lint همین سورس](docs/FINAL-SOURCE-VALIDATION.fa.md)
- [شواهد ساختاری حذف‌اطلاعات‌شده برای تیم سرور](docs/SERVER-API-EVIDENCE.sanitized.json)

بقیه گزارش‌های docs تاریخی‌اند؛ تعداد تست‌ها و موارد «منتظر آزمون» در آن‌ها وضعیت این بسته را نشان نمی‌دهند. سند اعتبارسنجی بالا مرجع نتیجه فعلی است. پچ `integration/history-v53.patch` پیشنهاد تاریخیِ **اعمال‌نشده** است و قبل از هر استفاده، باید با backend فعلی و مجوز مالک سرویس بازبینی شود.

## آنچه اصلاح شد

- هزینه کارشناسی، داوری، تعرفه دفترخانه و خدمات الکترونیک قضایی: فهرست ۱۰ → ۱۴ ابزار.
- فرم شرطی مبلغ توافقی داوری؛ خدمات چندانتخابی با آرایه JSON؛ تعداد نسخه صحیح و حداقل یک؛ کنترل گزینه نامعتبر و عدد/تاریخ.
- نگاشت مبلغ اصلی نتایج جدید، با حفظ جزئیات واقعی API و بدون نرخ یا نتیجه حقوقی ساختگی در اپ.
- غیرفعال‌کردن انتخاب ابزار حین ارسال و هشدار اینکه تأیید سرور، تأیید مستقل حقوقی نیست.
- تست‌های تازه قرارداد ورودی، خروجی‌های مشاهده‌شده و رفتار Compose.

مشکلات محتوایی استناد، تصویر، تاریخ و متادیتای تاریخچه در پاسخ خام API دیده شده‌اند و با این تغییرات اپ رفع نمی‌شوند. سایت/سرویس تولید تغییر یا deploy نشده است؛ صحت حقوقی تعرفه‌ها تأیید نشده است.

## امکانات و تصمیم‌های حفظ‌شده

- شروع مهمان از چت؛ درخواست ورود برای ارسال یا عملیات محافظت‌شده؛ بازگشت به پیش‌نویس بدون ارسال خودکار.
- گفتگوی عادی/SSE، توقف جریان، تاریخچه، بازخورد و ساده‌سازی؛ اسناد و ویرایش/دریافت Word؛ قوانین؛ تحلیل متن/عکس و پوشاندن محلی اطلاعات تصویر؛ مهلت و یادآور؛ حساب، پشتیبانی و طرح‌ها.
- ورود گوگل عمداً در رابط **نامرئی** است؛ placeholder غیرفعال ندارد.
- طراحی فارسی RTL، وزیرمتن، روشن/تیره، کارت‌های شیشه‌ای و چیدمان موبایل/تبلت؛ لوگوی درون برنامه شفاف و آیکون adaptive زمینه‌دار.
- نشست با Android Keystore، محدودیت حمل‌ونقل و مسیرهای API، محافظ پاسخ دیررس/ارسال تکراری و انقضای نشست. وجود این محافظ‌ها گواهی امنیت کامل نیست.

بسته `ir.hsai.mobile`، نسخه `2.0.0-native` / کد ۳، حداقل API 29، compile/target API 35. سرویس پایه: `https://hsai.ir/api/v1`. `openapi.json` مستند دریافتی اولیه است و عمداً به‌عنوان مستند اصلاح‌شده سرور معرفی نمی‌شود؛ اختلاف‌های زنده در گزارش آمده‌اند.

## محیط و آزمون

JDK 17 یا 21 (این مرحله با **JDK 21**)، Android SDK Platform 35 / Build Tools 35.0.0، Gradle Wrapper 8.9 و اینترنت برای دریافت وابستگی‌ها لازم است. `ANDROID_HOME` را تنظیم کنید یا مسیر محلی SDK را در `local.properties` قرار دهید؛ این فایل محلی در ZIP نیست.

```sh
chmod +x gradlew
./gradlew --no-daemon compileDebugUnitTestKotlin
HSAI_SKIP_SCREENSHOTS=1 ./gradlew --no-daemon testDebugUnitTest
./gradlew --no-daemon lintDebug
```

در محیط کم‌حافظه، کامپایل و آزمون را در فرایندهای جدا اجرا کنید. فرمان‌های دقیق کم‌حافظه و نتیجه‌ها در سند اعتبارسنجی نهایی آمده‌اند. `HSAI_SKIP_SCREENSHOTS=1` فقط ذخیره تصاویر را متوقف می‌کند؛ تست‌های بومی Compose/Robolectric همچنان اجرا می‌شوند.

سه تست زنده opt-in در اجرای عادی غیرفعال‌اند؛ موفقیت آزمون‌های محلی را نباید معادل اجرای آن‌ها یا مصرف دوباره سهمیه حساب دانست. برای آزمون حساب، فقط از متغیر محیطی و حساب تست مجاز استفاده شود؛ هیچ اعتبارنامه‌ای را به سورس یا فایل نمونه وارد نکنید.

برای ساخت اختیاری در محیط مالک پروژه، `./gradlew assembleDebug` استفاده می‌شود؛ این فرمان جزو خروجی تحویلی فعلی نیست. انتشار عمومی نیازمند ساخت Release، امضای اختصاصی مالک و آزمون دستگاه است. کلید Debug این محیط منتقل نشده؛ امضای ساخت جدید ممکن است با نصب قدیمی یکسان نباشد.

## محدودیت‌های ضروری

اجرای گوشی یا شبیه‌ساز کامل، SAF/دوربین، اعلان و زمان‌بندی یادآور، حفظ نشست پس از مرگ فرایند و برگشت درگاه هنوز باید روی دستگاه بررسی شوند: [چک‌لیست](docs/DEVICE-QA.fa.md). پرداخت، OTP، تغییر رمز/پروفایل، حساب دوم، اتمام سهمیه و صحت قانونی همه نرخ‌ها در ممیزی اخیر تأیید نشده‌اند. این سورس ادعای آمادگی بی‌قیدوشرط برای انتشار عمومی ندارد.
