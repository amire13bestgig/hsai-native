# چک‌لیست تأیید دستگاه واقعی

وضعیت فعلی تمام موارد زیر: **نیازمند اجرای دستگاه؛ تأیید نشده**. تست Compose/Robolectric جای این مرحله نیست. APK در این تحویل ساخته نشده است؛ مالک می‌تواند سورس را در Android Studio روی دستگاه خود اجرا کند.

مشخصات اجرا را ثبت کنید: مدل دستگاه، نسخه Android، اندازه پنجره، اندازه فونت، نسخه سورس و نتیجه هر ردیف. حداقل یک موبایل و یک تبلت؛ ترجیحاً Android 10 و Android 15 یا جدیدتر.

| مورد | انتظار |
|---|---|
| نصب/آیکون/اسپلش | تصویر زمینه‌دار کاربر آیکون اپ باشد؛ نشان طلایی در ماسک گرد و مربعی قطع نشود؛ اسپلش Android 12+ با نشان جدید |
| نوار وضعیت | روی موبایل/تبلت و روشن/تیره، زمینه یکنواخت سرمه‌ای و آیکون‌های خوانای روشن؛ بدون افتادن زیر ناچ |
| صفحه چت مهمان | ورود اجباری اولیه نداشته باشد؛ متن و عکس فقط در دستگاه آماده باشند |
| ورود پس از ارسال | «پیامت محفوظ است» نمایش داده شود؛ Back متن را پاک نکند؛ پس از ورود ارسال خودکار انجام نشود |
| ارسال پیش‌نویس | «ارسال پیام آماده‌شده» پس از ورود، فقط با لمس کاربر ارسال کند |
| فونت بزرگ | در اندازه فونت ۱٫۶، موبایل باریک و landscape، کارت‌ها/متن/دکمه‌ها خروج افقی نداشته باشند |
| صفحه‌کلید | کیبورد فارسی و انگلیسی، متن چندخطی، بستن کیبورد، تغییر جهت و تغییر ارتفاع پنجره؛ کادر ارسال قابل دسترس بماند |
| کارت‌ها | بدون جلوه برجسته/سایه‌های تو‌در‌تو و مستطیل سفید داخل کارت؛ عنوان‌ها کامل خوانده شوند |
| قطع شبکه | قبل و حین ارسال، شبکه قطع/وصل شود؛ وضعیت نامشخص توضیح داده شود؛ درخواست دوباره خودکار ایجاد نشود |
| توقف SSE | پاسخ دریافت‌شده باقی بماند، کادر آزاد شود و هشدار ادامه احتمالی پردازش سرور نمایش داده شود |
| تکرار درخواست | در وضعیت نامشخص، قبل از تکرار هشدار و تأیید آگاهانه لازم باشد؛ سهمیه مصرف‌شده به‌دروغ بازگشت‌داده‌شده نشان داده نشود |
| عکس گالری | JPEG دارای EXIF چرخش ۹۰/۱۸۰/۲۷۰ و mirror، PNG، فایل بزرگ و انتخاب لغوشده؛ جهت درست و خطای خوانا |
| دوربین/پوشاندن | اجازه و رد دسترسی، لغو عکاسی، پوشاندن اطلاعات و بازبینی نسخه ارسال‌شونده؛ عکس پس از خروج به نشست دیگر نرسد |
| اسناد/Word | دانلود و بازکردن در برنامه مستقل Word یا برنامه سازگار؛ متن فارسی و نام فایل سالم |
| تاریخ/مهلت | تاریخ شمسی کنار ISO میلادی با اصل انتخاب برابر باشد؛ روز مهلت بر اثر timezone جابه‌جا نشود |
| ICS | فایل فارسی طولانی در تقویم واقعی وارد شود؛ رویداد تمام‌روز یک‌روزه و یادآور یک روز قبل دیده شود |
| اعلان | درخواست مجوز Android 13+، رد مجوز، محدودیت باتری و اجرای یادآور؛ پس از حذف مهلت/خروج، یادآور لغو شود |
| نشست | بستن و بازکردن، مرگ فرایند، refresh و انقضا؛ هیچ داده حساب قبل در حساب دیگر نمایش داده نشود |
| درگاه | فقط در محیط آزمایشی مجاز مالک: لغو، بازگشت به اپ، مرگ فرایند و پاسخ pending/failed؛ موفقیت تنها از سرور تأیید شود |
| تاریخچه غنی | پس از اصلاح سرور، بازکردن مجدد سند/پرسش/استناد؛ بدون اصلاح سرور، محدودیت نبود فراداده ثبت شود |

برای آزمون زنده از داده ساختگی استفاده کنید. پرداخت واقعی، تغییر رمز یا دستکاری داده قبلی نیاز به اجازه جداگانه دارد.
