# بازبینی رابط بومی با مرجع زنده سایت

## محدوده

در این مرحله فقط سورس Kotlin/Compose، تست‌ها و مستندات پروژه تغییر کرده است. هیچ APK، AAB یا ZIP جدیدی ساخته نشده و فایل‌های تحویل قبلی دست‌نخورده‌اند. سایت و داده‌های اصلی و تنظیمات آن تغییر نکرده‌اند.

مرجع: ورود عادی از `https://hsai.ir/auth` با حساب مجاز کاربر، سپس مشاهده `/app`، `/app/account`، `/calculators`، `/laws` و `/pricing`. از صفحات در عرض ۳۹۰ و ۱۰۲۴ پیکسل اسکرین‌شات گرفته شد؛ ورود موفق بود. هیچ پیام، سند، تیکت، پرداخت یا ویرایش پروفایلی در سایت ایجاد نشد. اطلاعات ورود در سورس قرار نگرفت و فایل موقت نشست مرورگر بعد از بررسی حذف شد.

## تطبیق دقیق و محدودیت قراردادها

تطبیق از روی اسکرین‌شات واقعی و رنگ/استایل سایت انجام شده است؛ ادعای یکسانی پیکسل‌به‌پیکسل HTML و رابط بومی یا پوشش تمام ابزارهای وب مطرح نیست. حداقل اندازه لمس، ورودی‌ها و رفتار صفحه‌کلید مطابق اندروید حفظ شده است.

- ورود گوگل در API رسمی این پروژه قرارداد callback بومی ندارد. دکمه آن صریحاً «در وب‌سایت» است و توضیح می‌دهد نشست مرورگر به اپ منتقل نمی‌شود؛ موفقیت ورود بومی شبیه‌سازی نشده است.
- فرم عضویت مطابق قرارداد فعلی API شماره موبایل می‌خواهد؛ ظاهر تب عضویت با مرجع هماهنگ است اما عنوان «فقط با ایمیل» به‌دروغ نمایش داده نشده است.
- ورود پیامکی تنها وقتی تنظیم واقعی سرور آن را فعال کند نمایش داده می‌شود.
- امکاناتی که فقط در وب موجودند یا مجوز دستگاه می‌خواهند با تغییر ظاهری خودبه‌خود تأیید عملیاتی نمی‌شوند.

## بررسی انجام‌شده روی سورس نهایی

- کامپایل `compileDebugUnitTestKotlin` موفق؛ هیچ وظیفه ساخت APK/AAB اجرا نشد.
- **۵۰ آزمون موفق**: ۳۲ تست منطق/قرارداد و ۱۸ تست رابط بومی. دو تست زنده اختیاری این بار عمداً اجرا نشدند؛ در گزارش JUnit دو مورد skipped هستند، نه شکست.
- رندر هر ۱۰ صفحه در پنجره‌های ۳۲۰×۶۴۰، ۳۹۰×۸۴۴، ۷۶۸×۱۰۲۴، ۱۰۲۴×۱۳۶۶ و ۱۲۸۰×۸۰۰؛ حالت تیره تبلت نیز بررسی شد.
- هر ۱۰ فرم محاسبه‌گر و ۱۴ نوع پنجره در موبایل کوچک و تبلت رندر شدند.
- رسیدن با پیمایش به دکمه ورود و دکمه محاسبه با فونت ۱٫۶ برابر روی عرض ۳۲۰dp تست شد.
- تست‌های ورود اولیه، اعتبارسنجی ورود، ورودی‌های بومی عضویت، نشست بازیابی‌شده، ناوبری منو و حفظ پیش‌نویس اضافه/به‌روز شدند.
- پاسخ درخواست‌های تعامل تست رابط با interceptor محلی تأمین شد؛ داده واقعی حساب در تست‌ها و تصاویر بومی استفاده نشده است.
- Lint: **صفر خطا و ۶ هشدار نسخه جدیدتر وابستگی‌ها**.

رندرها متعلق به Compose واقعی روی Robolectric API 29 هستند، نه اسکرین‌شات گوشی یا شبیه‌ساز بوت‌شده. تأیید نهایی گوشی، صفحه‌کلیدهای واقعی، دوربین، اعلان و پرداخت همچنان آزمون دستگاه می‌خواهد. آزمون‌های رندر smoke test هستند و به معنی اثبات نبود تمام اشکالات بصری یا مقایسه خودکار پیکسل‌به‌پیکسل با سایت نیستند.

شواهد اجرای این مرحله در `verification/ui-refresh/` قرار دارند. شواهد ریشه `verification/` و تصاویر تحویل قبلی، تاریخی هستند و وضعیت سورس فعلی را توصیف نمی‌کنند.
