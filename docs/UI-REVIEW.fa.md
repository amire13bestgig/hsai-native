# بازطراحی بومی با سورس سایت نسخه ۵۳

> این گزارش مربوط به مرحله بازطراحی اولیه v53 است. برای وضعیت جدیدتر سورس، ۹۳ تست موفق و اصلاح مسیرها به [ممیزی جریان‌ها](FLOW-AUDIT.fa.md) مراجعه کنید.

## مرجع و دامنه
مرجع این مرحله آرشیو `hsai_src_v53.zip` ارائه‌شده توسط کاربر است؛ اجزای React و CSS آن خوانده و در Kotlin/Jetpack Compose بازپیاده‌سازی شدند. هیچ WebView یا رابط HTML اضافه نشده است. سرور و سایت اصلی تغییر نکرده‌اند. در این مرحله هیچ درخواست زنده با حساب کاربر و هیچ ساخت APK/AAB انجام نشده است؛ بسته تحویل فقط سورس است.

## تغییرات
- نشان رسمی سایت با مسیرهای برداری بومی، طیف سرمه‌ای و طلایی `#CE9F58` و پنج وزن واقعی وزیرمتن (۴۰۰، ۵۰۰، ۶۰۰، ۷۰۰ و ۹۰۰) از فونت سورس سایت.
- صفحه ورود با شبکه و نور رنگی پس‌زمینه، کارت سفید، انتخاب پیامک/ایمیل، تب عضویت و نشان قدرت رمز؛ بخش معرفی در عرض حداقل ۱۰۲۴dp، با حذف آن در فونت خیلی بزرگ. پیامک تنها با تنظیم فعال سرور نمایش داده می‌شود؛ متن هدیه نیز تابع تنظیم واقعی است.
- سایدبار ۲۸۸dp در عرض حداقل ۱۰۲۴dp با جستجوی گفتگوهای واقعی، ابزارها و حساب؛ ریل تبلت و منوی کشویی موبایل حفظ شدند. جلوگیری از ناوبری دوباره و بی‌اثرشدن پاسخ بازکردن گفتگو.
- کارت‌های گرادیانی نیمه‌شفاف، حباب سرمه‌ای پیام کاربر، کادر پیام شیشه‌ای و نمایش کاغذمانند سند.
- هدر سرمه‌ای شبکه‌ای برای قوانین، محاسبه‌گرها، مهلت‌ها و تعرفه‌ها؛ محدودسازی نقاشی نور به مرز هدر. تب‌های قوانین و دوره اشتراک داخل هدر قرار گرفتند.
- کارت ویژه طرح با رنگ سرمه‌ای/طلایی بر اساس داده `is_popular`؛ قیمت‌ها همچنان از API دریافت می‌شوند.
- جستجوی محلی در ۱۲ واژه‌نامه سایت، کارت‌های مقایسه قوانین و انتخاب منبع. واژه‌نامه راهنمای عمومی است و بررسی شرایط قانونی جداگانه لازم است.
- برچسب ثابت بالای ورودی، توضیح واحد و قالب مبلغ تومان؛ حفظ ورودی، پیمایش و رفتار بومی اندروید.

## آزمون سورس نهایی
- `compileDebugUnitTestKotlin` و `lintDebug` موفق؛ Lint صفر خطا و شش هشدار.
- `testDebugUnitTest`: مجموع ۷۹ مورد، **۷۶ موفق، صفر شکست/خطا، ۳ نادیده‌گرفته‌شده**. تست‌های زنده عمومی و حساب‌دار عمداً بدون مجوز اجرا و توکن فعال نشدند.
- ۲۹ تست رابط، ۳۲ تست Core، ۱۳ تست قرارداد API و ۲ تست خروجی محاسبه‌گر موفق بودند.
- مجموعه رندر شامل ده صفحه در عرض‌های ۳۲۰، ۳۹۰، ۷۶۸، ۱۰۲۴ و ۱۲۸۰dp، حالت تیره، ده فرم محاسبه‌گر و پنجره‌های گفتگو است. فونت ۱٫۶ برابر در موبایل کوچک نیز تست شده است.
- رندرهای ورود موبایل/عریض، پیام کاربر، قوانین و تعرفه ویژه بازبینی شدند؛ مشکل خروج نور هدر از مرز آن اصلاح و رندر مجدد بررسی شد.
- داده رابط و شبکه تست‌ها مصنوعی است؛ تصویرها متعلق به Compose روی Robolectric API 29 هستند، نه اسکرین‌شات گوشی واقعی یا مقایسه خودکار پیکسل‌به‌پیکسل با وب.

## محدودیت‌های عمدی
- شیشه بومی با گرادیان و شفافیت اجرا شده است؛ ادعای تکرار CSS backdrop blur وجود ندارد و متن عمداً محو نشده است.
- ورود گوگل وب معادل انتقال نشست به اندروید نیست؛ موفقیت بومی ساختگی نمایش داده نمی‌شود.
- مهلت‌های بومی مبتنی بر API حفظ شدند؛ محاسبه‌گر محلی مهلت وب با فرض‌های حقوقی آن بدون بررسی منتقل نشده است.
- ادعاهای مطلق امنیت/عدم خطای حقوقی و شمار ثابت مواد قانونی از سایت کپی نشدند.
- نصب، صفحه‌کلید واقعی، دوربین، اعلان‌ها و بازگشت درگاه همچنان آزمون دستگاه می‌خواهند. نتیجه ممیزی زنده پیشین در `API-AUDIT.fa.md` تاریخی است، نه اجرای دوباره در این مرحله.
